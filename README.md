# La bande sonore au propre : nettoyer une liste de lecture avec stringr

Activité Jigsaw Classroom (Aller plus loin dans le Tidyverse) : nettoyage des titres d'une liste de lecture Spotify avec quatre fonctions de `stringr`.

## Contenu

- `bande_son_stringr.qmd` : rapport reproductible (Quarto).
- `R/bande_son_stringr.R` : version script du même nettoyage.
- `data/My Spotify Library.csv` : export Spotify original.
- `data/My_Spotify_Library_messy.csv` : version désordonnée générée à partir de l'export original (voir le chunk `generation-fichier` du rapport).

## Utilisation

Ouvrir le projet à la racine du dossier, puis rendre le rapport avec `quarto render bande_son_stringr.qmd`. Les chemins sont relatifs à la racine.
